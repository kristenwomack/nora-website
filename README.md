# Nora Womack — Fashion Model

An image-forward fashion modeling portfolio built with Next.js, TypeScript, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

The featured project and image URLs are managed in `src/data/projects.ts`. Replace the placeholder imagery, project copy, and contact information before publishing.

## Commands

```bash
npm run lint
npm run build
```

## Deployment

The site is configured as a static export and deploys to GitHub Pages when
changes are pushed to `main`. GitHub Pages must be enabled with **GitHub
Actions** selected as the source.
